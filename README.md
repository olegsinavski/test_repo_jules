# Full-Stack Hello World: Next.js & FastAPI

This project demonstrates a simple full-stack application with a Next.js (React/TypeScript) frontend and a Python FastAPI backend. It showcases basic API communication to fetch and display a list of greetings.

## Features

*   **Frontend:** Next.js with TypeScript, styled with Tailwind CSS.
*   **Backend:** Python with FastAPI, serving a simple JSON API.
*   **API Endpoints:**
    *   `/api/`: Welcome message.
    *   `/api/greetings`: Returns a list of greetings.
*   **Development:** Concurrent script to run both frontend and backend servers.
*   **CI:** GitHub Actions for basic backend (pytest) and frontend (build) checks.

## Setup and Usage

### Prerequisites

*   Node.js (LTS version recommended, e.g., 20.x)
*   `pnpm` (version 8.x or later)
*   Python (version 3.9+ recommended)
*   `uv` (recommended for Python environment and package management, alternatively use `pip` and `venv`)

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/your-repo-name.git # Replace with your repo URL
cd your-repo-name
```

### 2. Environment Variables

This project doesn't require specific environment variables for its core functionality. If you add features that need them, create a `.env` file by copying from `.env.example`:

```bash
cp .env.example .env
```
And fill in the necessary keys. (Currently, `.env.example` is empty).

### 3. Install Node.js Dependencies

This will install dependencies for the root workspace (like `concurrently`) and the `frontend` workspace.

```bash
pnpm install
```

### 4. Setup Python Backend

**Using `uv` (Recommended):**

```bash
cd backend
uv venv # Create virtual environment
source .venv/bin/activate # Or .venv\Scriptsctivate on Windows
uv pip install -r requirements.txt
cd ..
```

**Using `pip` and `venv` (Alternative):**

```bash
cd backend
python3 -m venv .venv # Create virtual environment
source .venv/bin/activate # Or .venv\Scriptsctivate on Windows
pip install -r requirements.txt
cd ..
```
*(Note: The CI environment for this project encountered issues with virtual environment creation and uses globally installed Python dependencies as a fallback. For local development, using a virtual environment as described above is strongly recommended.)*

### 5. Running the Development Servers

This command uses `concurrently` to start both the Next.js frontend development server (usually on `http://localhost:3000`) and the FastAPI backend server (on `http://localhost:8000`).

```bash
pnpm dev
```

The frontend is configured to proxy requests from `/api/...` to the backend.

You should be able to see:
*   The Next.js application by navigating to `http://localhost:3000` in your browser.
*   The greetings page at `http://localhost:3000/greetings`.
*   The backend API root at `http://localhost:8000/api/`.
*   The backend greetings endpoint at `http://localhost:8000/api/greetings`.

### Available Scripts (from root `package.json`)

*   `pnpm dev`: Runs both frontend and backend development servers.
*   `pnpm dev:frontend`: Runs only the Next.js development server.
*   `pnpm dev:backend`: Runs only the FastAPI backend server.
*   `pnpm build:frontend`: Builds the Next.js application for production.
